# 図面からAR

生徒が紙にかいた第三角法の図面（正面図・平面図・右側面図）を撮影し、立体にしてAR表示するWebアプリです。ブラウザだけで動き、サーバーは使いません。

## 使い方

1. **用紙を出す**: 用紙の大きさ（A4・B4・A3）と1マスの大きさ（3〜15mm）、方眼の線のこさを選んで印刷します。印刷は「実際のサイズ（100%）」「余白なし」、横向きで。
2. **図面を読みこむ**: 図面を撮影するか、画像を選ぶ・貼り付ける（Ctrl+V）と読み取ります。四隅の■で傾きを、左上の小さな四角で用紙の種類とマスの大きさを自動で読み取ります。
3. **図面を直す・画面でかく**: 読み取った線を実線・かくれ線・消しゴムで直したり、白紙からかいたりできます。
4. **立体にする**: 3D表示、AR（iPad/iPhone は Quick Look、Android は Scene Viewer）、印刷したマーカーの上に表示（AR.js、Chromebook のカメラでも可）。

よく使う用紙は `sheets/` にPDFがあります。

## しくみ

- 三面図それぞれの輪郭の内側を半マス単位で塗り、押し出して重なった部分を立体にします（ボクセル彫刻）。角柱を組み合わせた形が対象で、穴やくぼみは復元できません。
- 方眼は薄い赤（ドロップアウトカラー）で、読み取りでは赤チャンネルを使い、さらに方眼の線ごとに明るさをそろえて消します。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（読み取り、立体化、AR） |
| `sheet.js` | 作図用紙のレイアウトとSVG生成（読み取りも同じレイアウトを使う） |
| `editor.js` | 三面図の編集画面 |
| `ardata/` | ARマーカー（歯車とOKA）とAR.js用データ |
| `sheets/` | 印刷用PDF（A4・B4・A3 × 5mm・10mm） |
| `tools/make_marker.py` | ARマーカー画像とパターンファイルの生成 |

## 公開

静的ファイルだけなので、GitHub Pages でリポジトリのルートを公開すればそのまま使えます。カメラとARには https のURLが必要です。
